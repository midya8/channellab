One score cannot rank every decision.

The default experiments both achieve 3/4 classification accuracy under a uniform prior, yet neither dominates the other. A failed direction includes a two-action task with a strict value gap. A passing direction includes a stochastic kernel K satisfying A K = B in both states.

Posterior call values are checked at every knot, not a sampled threshold grid. Between knots their difference is affine. This criterion uses exactly two states and a full-support prior. It must not be extended to multi-state models by checking a scalar score.
